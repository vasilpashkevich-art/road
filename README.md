# Дорожки

Браузерная игра в духе **Mini Motorways**: рисуй дороги от домиков к магазинам своего цвета, чтобы машинки успевали забирать заказы. Город растёт каждую неделю, и сеть дорог приходится перестраивать на ходу.

Вся игра — один файл `index.html`. Откройте его в браузере, ничего ставить не нужно.

## Как играть

- Проведи дорогу пальцем или мышкой от домика к магазину того же цвета.
- Белые фишки над магазином — заказы. Если их слишком много, запускается красный таймер; когда он заполнится, игра окончена.
- Каждую неделю (около минуты) приходят новые дороги и выбор из двух наград: кольцо, шоссе, светофор, мост, туннель или дороги.
- «Стереть» или правая кнопка мыши — убрать дорогу. Колёсико, кнопки «+/−» или два пальца — приблизить карту. «×2» ускоряет время, пробел — пауза.

## Что есть в игре

- 5 карт: Случайная, Минск, Бобруйск, Озеро, Предгорье (горы, туннели, леса).
- Магазины шести видов: киоск, квадратный, угловой, средний, длинный (парковка ёлочкой), прямой. Со временем магазины растут: этаж выше, вмещают больше заказов, заказывают чаще.
- Заказ сам вызывает ближайшую свободную машинку; магазины с тикающим таймером — первыми.
- Перекрёстки без светофора и кольца тормозят машинки; кольцо 3×3 и светофор снимают торможение.
- Шоссе над домами и реками (но не над горами), мосты и туннели.
- Стёртая дорога исчезает, только когда по ней доедут машинки, которые уже в пути.
- Машинки сразу переходят на новую дорогу, если сеть меняется.
- Сохранение: перезагрузка страницы продолжает игру. Обучение при первом запуске. Светлая и тёмная тема.

## Автотесты

В папке `tests/` — автоигрок и прогоны на всех картах. Нужны Node.js и Playwright (`npm i playwright`).

```bash
cd tests
# одна серия: 6 партий на карте Минск, до 900 с игрового времени, с проверкой состояния и сохранения
MAP=minsk INV=1 SAVE=150 PH=1 OV=1 PAR=2 node run.js ../index.html 6 900 out.json
python3 an.py .          # сводка: ошибки, нарушения правил, наезды, зависания
./matrix.sh ../index.html mx   # полная матрица: все карты, обычный режим, имитация игрока, все виды магазинов, 25-минутные партии без проигрыша
node ui.js               # проверки интерфейса в браузере (меню, карты, обучение, инструменты, сохранение, телефон, тёмная тема)
```

Переменные `run.js`: `MAP` — карта, `INV` — сверка 25 правил состояния каждую секунду, `SAVE=t` — сохранить и загрузить партию на секунде t, `PH` — поиск зависших машинок, `OV` — поиск наездов, `CH=5` — каждые 5 с стирать дорогу или разворачивать домик, `CYC` — ставить все виды магазинов по очереди, `TUNE='{"overflow":1e9}'` — игра без проигрыша.
